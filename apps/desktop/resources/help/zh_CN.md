# 开始使用

M7Arc 是使用 7-Zip 引擎的 macOS 归档与文件管理器。打开应用后，文件列表占据主窗口。上方七个按钮依次为添加、提取、测试、复制、移动、删除和信息。

**压缩文件：** 选择本地文件或文件夹，点击“添加”，选择输出路径、格式和压缩参数，再确认创建。

**打开归档：** 双击归档，或将其路径输入地址栏。没有常见扩展名的文件可通过“文件 → 7-Zip → 按格式打开”指定解析方式。

**提取归档：** 点击“提取”，选择输出目录和覆盖策略。在归档中选中成员时只提取这些成员；没有选择时提取全部。

**检查完整性：** 点击“测试”。测试会读取并解码所选内容，结果窗口报告引擎发现的错误。

本手册支持全文搜索，按 Command+F 聚焦搜索框。右上角可切换中英文；应用界面语言在“工具 → 设置 → 语言”中设置。

# 浏览、面板与视图

地址栏接受本地路径和归档内路径。输入 `~` 表示主目录；按 Backspace 或点击向上箭头进入上一级。返回嵌套归档的外层时，尚未保存的修改会先要求处理。

F9 切换单面板和双面板。每个面板有独立的地址、选择和状态栏；点击目标面板即可使其成为当前面板。F5/F6 在双面板模式下以另一面板为默认目标。

“查看”菜单提供大图标、小图标、列表和详细信息。详细信息中的“≡”按钮控制列显隐，点击列标题排序。归档列包含大小、压缩后大小、类型、时间、方法、加密、CRC、属性及格式提供的其他属性。

“平面视图”在归档中递归列出当前目录下的成员。“显示隐藏文件”控制本地隐藏项目。“刷新”重新读取当前目录或归档。

每个面板下方依次显示选择数量与总数、所选大小、当前项目大小和修改时间。

“收藏夹”提供十个槽位。“设置书签”记录当前位置；点击对应书签再次打开。主目录、`/Volumes` 下的卷和已挂载网络目录都可通过地址栏或书签访问。

# 选择、快捷键与文件操作

Command 单击可追加选择，Shift 单击选择连续区域。编辑菜单提供全选、取消全选、反向选择、按类型选择，以及通配符选择和取消选择。通配符示例：`*.txt`、`photo-??.jpg`。

| 快捷键 | 操作 |
| --- | --- |
| Enter | 打开当前项目 |
| Shift+Enter | 使用外部应用打开 |
| Backspace | 上一级 |
| F2 | 重命名 |
| F3 / F4 | 查看 / 编辑 |
| F5 / F6 | 复制到 / 移动到 |
| F7 | 新建文件夹 |
| F9 | 切换双面板 |
| Command+A | 全选 |
| Command+C / V | 复制 / 粘贴 |
| Command+X | 剪切本地项目 |
| Command+L | 输入路径 |
| Command+, | 设置 |
| Command+Q | 退出 |

部分 Mac 键盘需要同时按 Fn 才会发送 F2–F9 功能键。

本地删除将文件移到废纸篓。删除归档成员会重写归档，确认窗口列出所选范围。重命名、创建和删除是否可用由当前归档的实际更新能力决定。

本地文件可创建符号链接或硬链接；硬链接适用于同一文件系统上的文件。

# 格式与方法

“工具 → 格式与方法”显示当前引擎实际注册的归档格式、扩展名、编码方法和摘要算法，并提供搜索。内置 7-Zip 26.03 基线有 61 个 handler、25 个 codec 和 10 个 hasher。

| 创建类型 | 用途 |
| --- | --- |
| 7z | 多文件、固实压缩、AES 加密和文件名加密 |
| ZIP | 多文件与常见归档互操作 |
| TAR | 多文件打包和 POSIX 属性 |
| GZip / BZip2 / XZ | 单文件压缩流 |
| WIM | 文件镜像容器；本版本创建采用 Store |
| TAR+GZip / TAR+BZip2 / TAR+XZ | 先打包目录与多文件，再压缩为一个流 |

RAR/RAR5、Zstandard、DMG、ISO、APFS、HFS、NTFS、虚拟磁盘及可执行容器等格式可按相应 handler 读取。RAR 和 Zstandard 的创建能力不包含在内置引擎中。

格式能够读取，并不意味着能够创建或更新。固实资源、加密、分卷、格式版本和容器结构都可能影响当前归档的更新能力。只读归档仍可浏览、测试和提取。

# 创建与更新归档

“添加”窗口完整显示格式、压缩级别、方法、字典、单词大小、固实块、线程数、内存估计、分卷和密码选项。选项会按格式变化。

压缩级别和字典越大，通常越需要时间与内存。固实压缩可让多个文件共享压缩上下文；提取单个文件或更新归档时可能需要读取更多数据。内存值是所选参数的估计，实际用量还与数据及方法有关。

使用 GZip、BZip2 或 XZ 直接创建时，只能选择一个文件。压缩多个文件或文件夹时选择相应 TAR 组合格式。

更新模式：

- **添加 / 替换：** 添加新文件，并替换同路径成员。
- **更新：** 添加新文件，更新比归档成员更新的本地文件。
- **仅刷新：** 仅更新归档中已有的成员。
- **同步：** 让归档与所选输入范围同步，可能删除该范围内不再存在的成员。

已打开可更新归档时，点击“添加”可选择本地文件并写入当前归档目录。F7 可创建目录，“文件 → 新建文件”可创建空文件。

高级选项包括存储路径模式、包含和排除规则、时间字段、所有者、符号链接、硬链接、打开共享文件、保留访问时间和压缩后删除源文件。仅在明确需要时调整。

额外方法属性使用 `name=value`，多项以分号分隔，例如 `fb=64;mc=16`。属性必须由当前 handler 和方法支持；无效配置会报告引擎错误。

# 密码、加密与分卷

创建时在密码和确认框输入相同内容。7z 支持 AES 和文件名加密；ZIP 按所选加密方式写入。加密文件名后，读取目录也需要密码。单纯加密内容时，目录信息可能仍然可见。

打开或提取遇到加密内容会按需询问密码。只读操作的密码错误窗口可重新输入密码并重试，保留原输出路径、选择和提取参数。错误也可能来自损坏的数据；可结合“测试”结果判断。

分卷大小使用正整数及 `K`、`M`、`G`、`T` 后缀，例如 `100M`。多个大小依序应用，之后沿用最后一个值。

读取分卷归档时，把全部分卷放在同一目录，从第一卷打开，例如 `.7z.001`。缺少卷时查看错误详情，补齐后重新打开。文件分割工具产生的 `.001`、`.002` 是字节切片；它们与格式自身的多卷结构可能不同。

# 提取、路径与覆盖

提取对话框提供目标目录、同名子目录、重复根目录处理、元数据和密码选项。

| 路径模式 | 结果 |
| --- | --- |
| 保留完整路径 | 保留归档中的相对目录结构 |
| 不含路径 | 将文件平铺到输出目录 |
| 相对当前归档目录 | 去掉当前目录前缀，保留其下层结构 |
| 绝对路径 | 使用归档提供的绝对路径语义，适合明确了解该归档的高级操作 |

覆盖模式包括询问、替换、跳过、重命名传入文件、重命名已有文件。询问窗口支持对后续冲突统一替换或跳过。

“提取到当前位置”使用归档所在目录；“提取到同名文件夹”额外创建子目录。在本地面板选中多个归档时，可以一次提取或测试它们。

平铺时，不同目录可能包含同名文件；请按需要选择覆盖或自动重命名策略。

# 复制、移动与 Finder 拖放

双面板支持本地到本地、本地到归档、归档到本地、归档到归档四类传输。选择项目后使用 F5/F6，或拖到另一面板。

归档移动先完成目标写入，再删除源成员。如果目标阶段失败或被取消，保留源成员。归档到本地移动遇到跳过项目时，源归档全部成员保留，结果说明未完成的移动。删除源失败时，目标副本仍然存在。

将归档成员拖到 Finder 后，M7Arc 才开始提取实际文件。密码、进度与取消仍在 M7Arc 中显示。拖出文件夹会包含其子项。

在归档中按 Command+C，会先提取所选项目并放入系统文件剪贴板，之后可在 Finder 或另一归档中粘贴。剪贴板文件保存在临时目录，以支持关闭窗口后继续粘贴。

从 Finder 或本地面板复制文件后，可在可更新归档中按 Command+V 写入当前目录。本地剪切后粘贴到归档，仅在归档写入成功后删除本地源文件。

# 外部编辑与嵌套归档

F3 使用查看器，F4 使用编辑器。可在“设置 → 查看 / 编辑 / Diff”配置可执行文件或 `.app`；留空时使用系统默认应用。

归档成员会提取到独立临时目录，然后交给外部程序。修改并保存后返回 M7Arc，会看到“保存回归档 / 放弃修改 / 取消”选择。“文件 → 检查并保存归档内编辑”也可手动触发。

- **保存回归档：** 更新原来的精确成员；嵌套归档从内到外逐层保存。
- **放弃修改：** 从当前原归档恢复临时文件。
- **取消：** 保留当前编辑和临时文件，继续工作。

例如，在 `outer.7z` 内打开 `inner.zip`，再编辑其中的文本，保存时会先更新 ZIP，再更新外层 7z。

编辑期间如果原归档被外部程序修改，M7Arc 会要求重新打开，避免把改动写入身份已经变化的成员。失败时保留编辑过的临时文件；可从“工具 → 临时文件”查看目录位置并另存。

父归档必须支持更新才能保存回去。关闭应用前应处理待保存的修改。

# macOS 属性、备用数据流与注释

创建和提取窗口中的“保留 / 恢复 macOS 元数据”控制扩展属性、资源叉、Finder 信息及 ACL 等附加数据。归档中使用 AppleDouble 侧车保存需要的 Mac 信息；本地复制也保留这些属性。

在本地选中一个项目，使用“文件 → 扩展属性与资源叉”查看属性名称、大小及最多 4 KiB 的文本或十六进制预览，并可导出所选属性。

包含 Windows 备用数据流的归档可通过“文件 → 备用数据流”查看和提取这些流。它们作为独立文件导出；Windows 数据流与 macOS 资源叉是不同的数据结构。

在 ZIP 中选中一个成员，可通过“文件 → 注释”查看或编辑成员注释。此入口按格式能力开放。

“信息”显示当前归档或所选成员的大小、时间、方法和原始属性。权限、所有者等能否恢复还取决于输出格式与目标文件系统。

# 哈希、分割、合并与性能测试

在本地选择文件，打开“文件 → CRC / SHA”，选择一个算法或全部算法。窗口显示每个文件的真实摘要，可保存为清单。内置引擎提供 CRC32、CRC64、MD5、SHA1、SHA256、SHA384、SHA512、SHA3-256、XXH64、BLAKE2sp 十种 hasher；以格式与方法窗口为准。

“分割文件”按指定大小创建 `.001`、`.002` 等连续字节分卷。“合并文件”从选中的 `.001` 开始读取连续分卷，写入新的输出文件。合并完成前保留源分卷。

“工具 → 性能测试”使用官方压缩基准。可调整字典、线程、轮次和每轮耗时，查看编码与解码速度、评分、CPU 使用及平均结果，停止后也可重新运行或保存日志。

任务窗口提供暂停、继续、后台和取消。后台会隐藏窗口，任务继续执行；主窗口底部“任务进度”可再次显示。取消需要等待引擎完成必要收尾。失败详情列出各项错误。

# Finder Services、快速操作与预览

应用提供压缩、提取和测试的 Finder Services，接收多选文件。在“设置 → 系统”点击“安装 Finder 快速操作”，可安装对应的 Automator 工作流。

快速操作位于 `~/Library/Services`。安装后可在 Finder 的快速操作或服务菜单使用；系统未显示时，检查 macOS 的扩展和服务设置。

“设置 → 系统”列出格式关联，可将选中的格式设为 M7Arc 默认打开。也可在 Finder 的“显示简介 → 打开方式”中选择应用。

随包的 Quick Look 扩展显示归档目录、大小和方法；密码或缺失分卷等需要交互的情形，请在 M7Arc 主窗口打开。扩展是否加载取决于系统安装与扩展设置。

# 自解压程序与命令行

选择本地文件，点击“工具 → 创建自解压程序”，选择输出类型、压缩方法、级别与密码。默认使用 LZMA2 7z 数据，生成前会测试载荷完整性。

| 输出 | 使用方式 |
| --- | --- |
| macOS 图形 `.app` | 内嵌归档，双击后选择目录和输入密码 |
| macOS 图形 DMG（内嵌） | DMG 中放置独立图形提取器 |
| macOS 图形 DMG（外置） | 图形提取器与 `Payload.7z` 保持在同一目录 |
| macOS `.command` | 当前 Mac 架构的官方 console SFX，在 Terminal 中运行 |
| Windows GUI / Console `.exe` | 官方 x86 模块，在支持 32 位程序的 Windows 上运行 |

Mac 图形提取器提供进度和 macOS 元数据恢复。Mac 产物采用 ad-hoc 签名。Windows 输出没有安装或解压后运行命令。

随应用提供完整官方命令行：

```sh
"/Applications/M7Arc.app/Contents/MacOS/7zz" i
"/Applications/M7Arc.app/Contents/MacOS/7zz" a archive.7z Documents
"/Applications/M7Arc.app/Contents/MacOS/7zz" x archive.7z -oextracted
"/Applications/M7Arc.app/Contents/MacOS/7zz" h -scrcSHA256 archive.7z
"/Applications/M7Arc.app/Contents/MacOS/7zz" b
```

`i` 显示格式和算法，`a` 创建或更新，`x` 提取，`t` 测试，`h` 计算摘要，`b` 运行基准。路径含空格时使用引号。

Console SFX 需要接收者使用相应 Mac 架构。它支持自己的测试、提取、输出目录和密码参数，不会自动执行归档内的文件。Windows SFX、Mac console SFX 和图形提取器是不同的发布类型。

# 设置、安装与卸载

设置提供六页：系统、菜单、文件夹、查看 / 编辑 / Diff、常规设置、语言。菜单页可显示或隐藏常用命令；文件夹页设置启动和临时目录；常规页控制隐藏文件、交替行背景、自动刷新、元数据和窗口位置。

语言支持跟随系统、简体中文和英文，重新启动后生效。帮助窗口中的语言切换只改变当前手册。

从项目 GitHub Release 下载对应 Apple Silicon 或 Intel 的 DMG，打开后把应用拖到“应用程序”。更新时退出旧版本，再替换应用。发行包采用 ad-hoc 签名，尚无 Developer ID 签名与 Apple 公证；首次打开请按 macOS 显示的系统提示操作。

卸载时把 M7Arc.app 移到废纸篓。若安装过快速操作，可同时移走 `~/Library/Services/M7Arc Compress.workflow`、`M7Arc Extract.workflow`、`M7Arc Test.workflow`。需要恢复其他默认打开应用时，在 Finder 的“显示简介”中修改对应格式。

版本使用 SemVer：补丁版本用于修复，次版本增加功能，主版本表示约定的重大变化。`alpha`、`beta` 和 `rc` 表示预发布。

# 常见问题与限制

**为什么某个菜单是灰色的？** 当前选择、任务状态或归档的实际能力不满足条件。例如，RAR 不能更新，注释只对支持它的 ZIP 成员开放，复制需要先选择项目。

**能打开为什么不能创建？** 读取和写入是独立能力。查看“格式与方法”的读写标记。

**密码正确仍然失败？** 检查分卷是否齐全，并运行测试。错误详情可能指出数据损坏、输入读取失败或不支持的方法。

**嵌套修改保存失败？** 确认每一层可更新且外层未被其他程序改动。保留临时目录中的编辑文件，重新打开归档后另行写入。

**空间不足或内存不足？** 改用有空间的输出和临时目录，减少字典、线程或同时处理的数据规模。更新和跨归档传输可能需要临时空间。

**Finder 没有显示扩展？** 检查应用是否已安装、启动，以及 macOS 扩展和服务设置。主应用可以独立完成归档操作。

已知限制：当前发行未经过 Apple 公证；内置读取能力不包含 RAR 创建；TAR 组合需要重建外层；console SFX 对应一种 Mac 架构；Windows 属性不直接等同于 macOS 文件系统属性。
