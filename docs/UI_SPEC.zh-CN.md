# M7Arc 界面与交互规格

M7Arc 使用 C++ 与 Qt Widgets 实现 7-Zip File Manager 的文件管理器工作流。主界面保留六组菜单、七个工具栏动作、可编辑地址栏、属性列表和状态栏，采用 macOS 系统字体、单色轮廓图标、柔和灰色工具栏与圆角控件。默认单面板，F9 切换双面板。压缩参数、归档结构和底层格式能力在各自窗口完整呈现。

完整命令与源码映射见 [File Manager 功能规格](FILE_MANAGER_SPEC.zh-CN.md)，格式与方法数据见 [格式能力目录](FORMAT_CAPABILITIES.zh-CN.md)，各个对话框的字段和联动见 [对话框规格](DIALOG_SPEC.zh-CN.md)。

界面层次主要由间距、表面明度和细分隔线表达。控件圆角保持一致，密集参数窗口使用分组间距区分资源、路径、分卷与加密。大图标、文字显隐和列表密度继续遵循查看菜单的设置。

正式 Qt 实现采用 macOS 原生样式、系统调色板与系统字体；窗口外框、标题栏和窗口按钮交由平台管理。图标优先映射语义匹配的 SF Symbols 或平台图标，缺少适合项时回退到随应用提供的 Lucide 图标。文件与文件夹图标通过平台文件图标接口取得。表格选择、键盘焦点和系统强调色保持一致。

文件系统的动态 7-Zip 菜单包含按类型打开、提取文件、提取到当前位置、提取到同名目录、测试、添加、快速添加为 7z/ZIP，以及压缩后创建邮件草稿。按类型打开保留原版 `*`、`#`、`#:e`、7z、ZIP、CAB、RAR 规则；自动打开可识别完整格式目录。

## 3. 文件与归档浏览

单击选择，Shift 连续选择，Cmd/Ctrl 多选。双击或 Enter 进入文件夹与归档；普通文件交给默认应用。归档内文件先提取到工作目录再外部打开，嵌套归档保留父层关系和完整虚拟路径。地址栏可以输入本地路径，也能显示归档内部路径。

“内部打开”“内部打开 `*`”“内部打开 `#`”及“按类型打开”保留各自引擎规则。归档根目录的向上操作返回外层；普通目录返回父目录。平面视图展示递归条目，路径前缀保留以区分不同目录下的同名文件。

详细列表按 provider 枚举全部字段。常用列包括名称、大小、压缩后大小、类型、修改时间、属性；归档列包括方法、加密、CRC、块、主机系统、权限、时间、偏移、链接和其他格式属性。列选择通过地址栏旁入口或表头菜单打开，按文件夹类型持久化。名称列保持可见。

数字按原始数值排序，日期按原始时间排序。时间显示支持日期、分钟、秒、100 ns、ns 五级精度与 UTC；显示精度独立于归档保存精度。文件浏览采用模型数据，滚动只读取已加载的属性值。

双面板复制/移动默认目标为另一面板，Shift+F5/F6 使用同一面板路径。拖放覆盖本地到本地、本地到可写归档、归档成员拖出提取和面板间传递。操作完成后刷新源与目标，保留仍然存在的选择和焦点。

## 4. 格式与方法窗口

窗口包含三个页签：归档与容器、压缩方法与过滤器、校验和算法。当前完整 7-Zip 26.03 基线包含 61 个 handler、25 个 codec、10 个 hasher；Hash 的清单读写单独表达。七类直接归档写入为 7z、ZIP、GZip、BZip2、XZ、TAR、WIM。

| 控件 | 行为 |
| --- | --- |
| 格式搜索 | 按格式名称、扩展名和别名搜索，如 RAR、DMG、DOCX |
| 能力筛选 | 全部、可创建归档、只读格式 |
| 类别筛选 | 归档与软件包、压缩与编码流、磁盘与分区、文件系统、可执行文件与固件、文档与媒体等 |
| 目录表 | 格式、扩展名/别名、读取/写入能力、类别；分页浏览 |
| 格式详情 | 能力说明、限制、扩展名；打开该类示例；可写格式提供“创建…” |
| 编码器与过滤器页 | 方法名称、编码/解码方向及注册信息 |
| 摘要算法页 | 名称、位数及可用计算能力 |

格式目录展示全部读取能力，“添加到压缩包”下拉展示可创建能力。TAR+GZip、TAR+BZip2、TAR+XZ 是组合预设，显示两步处理链。RAR、DMG、APFS、VHD/VHDX、Zstandard 等按照当前基线的真实能力显示。

## 5. 添加到压缩包

添加窗口采用原版两列表单，主参数默认可见。顶部是归档路径与名称；左侧从格式依次到参数，右侧为更新、路径、操作选项和加密。仅原版独立 Options 中的链接、元数据、时间选项，以及额外编码方法放在“更多选项”。

| 分组 | 默认可见字段 |
| --- | --- |
| 输出 | 归档路径/名称、历史、浏览；七类直接格式和三个 TAR 组合预设 |
| 压缩 | 等级、方法、字典、词大小/模型阶数、固实块 |
| 资源 | CPU 线程、硬件线程、压缩内存预算、压缩与解压内存估计 |
| 分卷与参数 | 分卷大小、大小预设、多段分卷序列、自由方法参数 |
| 更新与路径 | 添加并替换、更新并添加、只更新已有、同步；相对、完整、绝对路径 |
| 操作 | SFX 及其目标平台、压缩共享文件、成功后删除源文件 |
| 加密 | 密码、确认、显示密码、加密方法、加密文件名 |

| 更多选项 | 字段 |
| --- | --- |
| 文件元数据 | 符号链接、硬链接、NTFS 流、安全信息；按平台与格式能力启用 |
| 时间 | 精度、修改/创建/访问时间的默认/存储/不存储、归档时间取最新文件、保持源访问时间 |
| 高级编码 | 引擎支持的额外方法、预处理过滤器和参数 |

选择格式后联动等级、方法、字典、词长、固实、线程、加密和 SFX。ZIP 提供 Deflate、Deflate64、BZip2、LZMA、PPMd，密码方式区分 ZipCrypto 与 AES-256；7z 支持 AES-256 与文件名加密。TAR 的 GNU/POSIX 是头格式选择，WIM 创建使用 Store。原版普通方法和引擎高级方法的区别保留在 [格式能力目录](FORMAT_CAPABILITIES.zh-CN.md)。

GZip、BZip2、XZ 直接创建要求一个普通文件。多文件或目录使用显式 TAR 组合预设，并展示“打包 TAR → 压缩流”两阶段。格式切换后保留适用选项，清除不适用状态；分卷、密码确认和单流输入在提交前给出具体错误。

正式应用从引擎计算内存估计，结构化字段与自由参数进入同一更新计划。密码仅保留在当前任务内存中。SFX 清楚标明目标平台，当前官方 Windows 模块显示 `.exe`。

## 6. 提取、冲突与内存请求

提取窗口包含目标目录、同名子目录开关与名称、路径模式、根目录消重、覆盖模式、密码和元数据恢复。路径模式保留完整路径、当前路径、不含路径及明确的绝对路径选项。

覆盖模式区分询问、直接覆盖、跳过、自动重命名新文件和自动重命名已有文件。冲突对话框显示双方名称、大小与时间，提供是、全部是、自动重命名、否、全部否、取消。

加密归档在需要时请求密码，密码输入可切换可见。解压内存超过设置时显示所需内存、允许上限、允许/跳过归档、当前操作记住选择、继续/取消。操作诊断保留每个失败对象及具体原因。

## 7. 属性、编辑与文件工具

信息按钮打开属性窗口，按文件、文件夹、当前归档、外层归档分组展示。多选汇总文件数、目录数、大小和压缩大小；归档层包含方法、固实、块、偏移、物理大小、头部/尾部大小、错误与警告。属性摘要可以复制。

查看器、编辑器与 Diff 工具在设置中独立配置。包内文件外部修改后，编辑会话记录原始成员与归档层，提供保存回归档、放弃修改、取消。嵌套归档按层回写，失败时保留修改内容；只读父层需要另存。

分割窗口显示源、目标、每卷大小和卷名示例；合并窗口选择 `.001` 首卷并展示连续部分与输出。复制、移动、新建、重命名、注释、链接各有明确目标和确认操作。备用流与 macOS 扩展属性分别呈现其类型和来源。

临时文件窗口列举可清理项目、用途和大小，支持选择、进入、删除、刷新、过滤及属性。仍在使用的编辑临时文件保持可识别状态。

## 8. 作业与基准测试

每项作业展示动作、对象、扫描/处理/写入阶段、已处理/总量、文件数、速度、时间、压缩后大小、压缩率和错误。进度窗口提供暂停/继续、后台/前台、取消、诊断和完成结果。归档提交阶段的按钮状态反映实际可取消范围。

后台运行保持文件管理器响应；参数请求通过密码、覆盖与内存窗口返回当前任务。关闭窗口时存在运行任务或未保存编辑，明确处理继续运行、保存、取消与退出。

基准测试独立于普通作业。窗口显示字典、CPU 线程、轮数、内存需求；压缩和解压各有当前/结果行，包括数据量、速度、CPU 使用率、评级/使用率和评级；底部显示总体评级、用时、CPU/系统信息与日志。支持开始、停止和重新开始，评级沿用上游定义。

## 11. 原型交付

[离线交互原型](../design/index.html) 是完整独立 HTML，可直接在浏览器打开；[内嵌界面片段](../design/m7arc-ui.html) 用于应用内预览。源文件位于 [design/prototype/](../design/prototype/)，包括窗口结构、样式、命令目录、格式目录、对话框和交互状态。

原型可浏览示例文件与嵌套归档、切换单/双面板、切换视图与列、选择和排序、使用收藏夹、打开全部菜单、搜索格式与方法、联动压缩选项，并模拟文件操作、任务暂停/继续/取消、基准测试、编辑回写和临时文件清理。格式目录和算法数量使用当前源码基线。

在仓库根目录执行 `python3 design/prototype/build.py`，可把源文件和随仓库保存的 Lucide 图标库打包为两个 HTML 入口。独立入口内嵌图标库，图标许可随仓库保存；应用内片段使用宿主提供的同一图标库。打开离线原型无需运行服务或安装前端依赖。

## 12. 已知边界

当前交付为可交互 HTML 原型与 Qt 实施规格，文件、归档内容、进度和基准测试结果使用内置示例。Qt 应用、实际文件操作、平台关联、Finder 扩展、Quick Look、原生拖放与引擎回调需要按工程路线实现。原型的窗口内容在同一画布中切换，正式 Qt 版本使用独立对话框和系统菜单。

Windows Registry、COM Shell 扩展、Zone.Identifier、NTFS 安全描述符、备用流、Directory Junction 和 WSL 重解析链接分别映射其适用平台能力。macOS 元数据与 Windows 元数据保留各自语义。Windows SFX 生成 `.exe`，macOS 原生 SFX 是独立交付能力。
