# 十万成员 ZIP 的列表响应

在 macOS 27.0、Apple Silicon、Qt 6.11.2 的原生 Cocoa 窗口中，使用真实含 100,000 个普通空文件的 ZIP，分别测量引擎后台读取、Qt 行转换、`FilePane` / `ArchiveModel` 发布和四种视图切换。文件名为连续短路径 `entry-000000.txt` 至 `entry-099999.txt`。

| 项目 | 本地实测 |
| --- | ---: |
| 后台读取完整归档目录 | 494 ms |
| 主线程转换归档行 | 225 ms |
| 发布完整模型 | 254 ms |
| 大图标切换调用 | 7 ms |
| 大图标布局期间最大事件循环间隔 | 35 ms |
| 小图标布局期间最大事件循环间隔 | 22 ms |
| 列表布局期间最大事件循环间隔 | 18 ms |
| 详细视图切换期间最大事件循环间隔 | 27 ms |

模型保留全部 100,000 行和该归档的 13 列。首次行转换与模型发布的最大事件循环间隔为 500 ms；视图切换没有数秒停顿。事件循环使用 16 ms 定时器观测，数值包含系统调度与绘制时间。

图标视图采用 Qt 分批布局，每批 256 项，并使用统一项目尺寸。模型缓存标准文件和文件夹图标；发布归档时一次应用条目、目录和属性列。未变化的排序与目录设置不重新构建列表。

本次测量覆盖大量短路径空成员的目录浏览；归档解码耗时另由实际压缩数据与编码方法决定。
